# Lyre project tracker

Project-management side of lyre-public, kept in the repo so it travels with the code.
(This folder is served by GitHub Pages along with everything else on `main`; keep it public-safe.)

- **Work items:** GitHub issues in this repo.
- **Decisions:** `decisions/`, one file per decision. See [WHAT-IS-AN-SDR.md](WHAT-IS-AN-SDR.md).

`/pm lyre-public` reads this folder (`tracker_path` / `sdr_dir` in `~/pantheon/.claude/projects.json`).
